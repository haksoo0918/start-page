## 🛠️ 브라우저 홈(새 탭)으로 설정하는 2가지 방법

---

### 🌟 [방법 1] 크롬 확장 프로그램으로 등록 (서버/터미널 실행 0%, 가장 추천!)

로컬 서버를 켤 필요 없이, 컴퓨터를 켜고 브라우저를 열거나 새 탭(`Ctrl + T`)을 누르면 **0.01초 만에 네이티브로 대시보드가 열리는 가장 간편한 방식** 입니다.

#### 1단계: 프로젝트 빌드
프로젝트 루트에서 빌드 명령어를 실행합니다:
```bash
npm run build
```
➔ 빌드가 완료되면 `dist` 폴더에 확장 프로그램 패키지가 생성됩니다.

#### 2단계: 브라우저에 등록하기 (10초 소요)
1. **Chrome / Edge / Whale 브라우저** 를 엽니다.
2. 주소창에 브라우저별 확장 프로그램 관리자 주소를 입력하고 이동합니다:
   - **Chrome**: `chrome://extensions`
   - **Edge**: `edge://extensions`
   - **Whale**: `whale://extensions`
3. 우측 상단의 **`[개발자 모드]`** 스위치를 켭니다.
4. 좌측 상단에 나타난 **`[압축해제된 확장 프로그램을 로드합니다]`** (또는 `[로드]`) 버튼을 클릭합니다.
5. 파일 선택 창에서 본 프로젝트의 **`dist` 폴더** 를 선택합니다:
   - 경로: `c:\Users\hakso\_work\browser-home\dist`
6. **완료!** 이제 브라우저를 열거나 새 탭(`Ctrl + T`)을 누르면 대시보드가 즉시 열립니다.

---

### 🌐 [방법 2] 무료 웹 호스팅(Vercel / GitHub Pages)에 배포하기

네이버나 구글처럼 **나만의 고유 인터넷 주소(예: `https://my-home.vercel.app`)** 를 만들어 어떤 PC/노트북/스마트폰에서도 접속할 수 있는 방식입니다.

#### 1단계: Vercel로 1분 무료 배포
터미널에서 아래 명령어를 실행하고 엔터를 누르면 배포 주소가 즉시 발급됩니다:
```bash
npx vercel
```

#### 2단계: 브라우저 시작 페이지로 등록
1. 브라우저 설정 ➔ **[시작 그룹]** (또는 `시작, 홈 및 새 탭`) 메뉴로 이동합니다.
2. **`특정 페이지 열기`** 에 발급받은 Vercel 주소를 입력하고 저장합니다.
3. 새 탭 열 때도 뜨게 하려면 크롬 웹스토어의 무료 확장 프로그램(예: *New Tab Redirect*)에 해당 주소를 등록합니다.
