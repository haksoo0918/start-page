## 🛠️ 브라우저 시작 페이지(홈)로 설정하는 방법

로컬 서버를 켤 필요 없이, 컴퓨터를 켜고 브라우저를 열면 **0초 만에 대시보드가 열리는 가장 간편한 방식** 입니다.

### 1. Chrome (크롬)
1. 크롬 우측 상단 메뉴 `⋮` ➔ **[설정]** 클릭
2. 좌측 메뉴에서 **[시작 그룹]** 클릭
3. **`특정 페이지 또는 페이지 모음 열기`** 선택 ➔ **`새 페이지 추가`** 클릭
4. URL 입력: `https://haksoo0918.github.io/start-page/`

### 2. Edge (엣지)
1. 엣지 우측 상단 `...` ➔ **[설정]** 클릭
2. 좌측 메뉴에서 **[시작, 홈 및 새 탭]** 클릭
3. **`Edge가 시작될 때`** 항목에서 **`다음 페이지를 열 수 있음`** 선택 ➔ **`새 페이지 추가`** 클릭 후 URL 입력
